# 宏观交易培养 · 饲料库（macro-knowledge）

本仓库是「培养线」的唯一饲料容器，负责饲料的**吞吐**（按顺序摄入、按单元推进）与**容纳**（分类归档、长期可检索）。
「监测线」（豆包定时任务 `基金早晚盘监控`，每日 08:30 / 20:30）从这里读取**规则层**内容作为硬约束，但预警阈值与持仓基准同时写死在定时指令内，避免读不到时失效。

## 两条线怎么同步

| 线 | 触发 | 读写本仓库的哪部分 | 谁更新 |
|---|---|---|---|
| 培养线 | 用户手动发「开始今日宏观培养」 | 读 01→05 全目录；写 `05_templates/进度记录.md` | 培养会话 |
| 监测线 | 每日 08:30 / 20:30 自动 | 只读 `03_rules/` 与 `05_templates/`；日志写到 `isea7771/fund-monitor` | 定时任务 |

同步点只有一个：`03_rules/强制规则.md` + `05_templates/进度记录.md`。规则变了，两条线同时生效；进度变了，培养线从断点继续。

## 目录结构

```text
01_theory/      理论基础：宏观经济、固定收益、衍生品、Python 数据处理
02_frameworks/  交易框架：周期与概率决策、宏观交易员访谈、跨资产联动
03_rules/       强制思维规则（两条线共用的硬约束）
04_history/     历史行情与研报复盘归档
05_templates/   进度记录、交易日志、周报模板
```

## 添加饲料的规范

1. 按目录编号放置，不新建平级目录。
2. 文件名格式：`序号_主题.md`，例如 `01_theory/01_曼昆宏观_货币政策章节.md`。
3. 大段 PDF 先转 Markdown 或先做摘要，摘要必须保留：机制、条件、失效边界、可操作规则；删掉叙事性套话。
4. 每加入一份文件，在 `05_templates/进度记录.md` 登记一行，状态写「未读」，由培养线按顺序推进。
5. 书籍原文只读不改；补充心得写进同名 `.notes.md`，不要动原文。

## 边界

净值型公募不存在保本与每月必正收益；本仓库只承载训练资料与监测记录，不构成投资建议，实盘决策由本人承担。
