# 04_history · 历史复盘归档

## 归档规范

文件名：`YYYYMMDD_事件名.md`，例如 `20230601_美债上限危机.md`

每份必含四块：

1. 时间线：事件起因、关键政策动作、市场顺序反应
2. 市场反应：10 年期国债收益率、股指、汇率、黄金的实际区间变动
3. 当时研报：至少两份当时的主流判断，标注对错
4. 事后复盘：哪个信号提前给了提示、哪个信号是噪着、当时谁错了、错在哪
