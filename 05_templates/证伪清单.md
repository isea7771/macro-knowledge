# 证伪清单模板

每个观点必须填写。不填完不发出去。直接服务于 R2（必写失效信号）。

```text
## 观点编号：YYYYMMDD-01
- 观点一句话：
- 置信度（0–100）：
- 情景 A（概率 x%）｜触发信号｜对应资产表现：
- 情景 B（概率 y%）｜触发信号｜对应资产表现：
- 情景 C（概率 z%）｜触发信号｜对应资产表现：

### 什么已被 price in（R5）
- 未定价 / 部分定价 / 已充分定价（三选一）：
- 依据：

### 双路信号（R6）
- 文本叙事信号（研报/央行措辞/新闻）：
- 微观结构信号（成交量/基差/利差/波动率）：
- 是否背离：是 / 否；背离点：
- 背离 → 置信度强制降一档

### 证伪条件（必须可观测、可验证）
- 未来 N 天（N= ___）内出现以下任一信号，则承认本观点错了：
  1.
  2.
  3.
- 到期复盘：成立 / 证伪 / 模糊；归因：逻辑错 / 数据错 / 情绪扰动

### 决策质量记账
- 当时决策是否合理（不看结果看过程）：
- 结果：赚钱 / 亏钱；与决策质量是否一致：
```

> 归档：与本观点相关的行情、文本一起放入 `04_history/`，文件名与观点编号一致。
